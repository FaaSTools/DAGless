# BWA

## BWA

Contains the high-level wrapper of the BWA executables. This must be installed prior to running the BWA workflow using the following command:

```bash
mvn clean install
```

## BWA Workflow

Contains the conposition of the BWA executables as it was used in Fissionless.

## Resources

Contains all resources compiled for AWS Lambda and Google Cloud Functions. In case you want to compile the BWA for a different platform, check this GitHub repository: [BWA](https://github.com/lh3/bwa)
