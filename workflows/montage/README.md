# Montage

## Montage

Contains the high-level wrapper of the Montage executables. This must be installed prior to running the Montage workflow using the following command:

```bash
mvn clean install
```

## Montage Workflow

Contains the conposition of the Montage executables as it was used in Fissionless.

## Resources

Contains all resources compiled for AWS Lambda and Google Cloud Functions. In case you want to compile the Montage for a different platform, check this GitHub repository: [Montage](https://github.com/Caltech-IPAC/Montage)
